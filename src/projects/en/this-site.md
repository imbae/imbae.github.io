The site you're looking at.

- Static site built with **Eleventy (11ty)** — no client framework
- Bilingual: Korean (`/`) and English (`/en/`), with `hreflang` and per-page OG tags
- Content lives in `src/_data` (site, projects, books) and Markdown notes
- Notes and projects cross-link — each project page collects its "related notes"
- RSS feed, automatic deploy via GitHub Actions
- Dark + lime design, honours `prefers-reduced-motion`

Source: [github.com/imbae/imbae.github.io](https://github.com/imbae/imbae.github.io)
