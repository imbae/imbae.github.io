**캘린더를 메인 축**으로 두고, 위치 기반 자동 기록과 개인/업무 구분을 결합한
크로스플랫폼(모바일 + PC) 개인 기록 앱입니다. 캘린더는 갤럭시/구글 캘린더 수준의
기본기를 기준선으로 삼고, 그 위에 **"장소 기반 근접 알림"**을 차별화 축으로 키웁니다.

## 캘린더 코어 (구현 완료)

- 월간 · 주간 · 일간(타임라인) · 연간 · 목록(아젠다) 뷰
- 일정 CRUD, 시간 범위 · 여러 날 일정, 반복 일정, 리마인더 알림
- 음력 캘린더(한국천문연구원 데이터, 1391–2050), 공휴일 표시
- 캘린더 자체 검색, 일정 색상 커스터마이징, 요일 색상 + 주차 표시

## 위치 기반 기능 (차별화 축)

- **두 갈래 기록** — ① 일정 기반: 날짜/시간에 묶인 일정(장소 태그 가능)
  ② 장소 기반: 위치 자체에 묶인 메모, 그 장소 근처에 가면 알림
- 지도에 일정 장소와 장소 메모를 함께 표시 (마커 라벨로 구분)
- **일정 자동 완료 체크** — 지오펜스로 방문을 감지해 일정을 자동 처리
- **하루 동선 자동 요약** — 위치 권한만 켜두면 하루 방문지가 자동으로 정리됨
  (상시 GPS 대신 OS 지오펜싱 등 저전력 방식 우선)

## 워크스페이스 · 플랫폼

- 모든 데이터(일정 · 장소)는 **개인 / 업무** 워크스페이스로 분리.
  단, 하루 자동 요약과 통합 검색은 예외적으로 두 워크스페이스를 합쳐서 동작
- 모바일(iOS · Android): 캘린더 + 지도 + 검색 + 요약 풀 기능
- PC(Windows): 캘린더 중심의 상시 플로팅 위젯 (프레임리스 · 항상 위)

## 구조

- Flutter · Riverpod, 로컬 저장소 Drift(SQLite), 모노레포(`apps/` + `packages/core·data·ui_kit`)
- 지도: mapbox_maps_flutter + Mapbox Studio 커스텀 스타일
- 비주얼: 무채색 베이스 + 포인트 컬러 하나(개인 워크스페이스 액센트 블루), 서체 Noto Sans KR
- Flutter 경험이 적은 사용자를 위해, 구조가 새로 생길 때마다 `docs/guides/`에 초보자용 가이드를 함께 작성
