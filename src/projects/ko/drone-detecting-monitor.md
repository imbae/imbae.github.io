드론 탐지 장비가 보내는 데이터를 받아 상황을 지도에 띄우고, 나중에 다시 볼 수 있게
기록하는 모니터링 클라이언트입니다.

## 하는 일

- **수신 파이프라인** — UDP 패킷 수신 → CRC16-CCITT 검증 → 메시지 타입별
  (기준 장치/RTK, 탐지된 드론, 탐지 장비 상태, 제어) 이벤트 발행
- **지도 시각화** — GMap.NET 기반으로 탐지 장비·기준 위치·탐지 표적 마커와 경로 갱신
- **로그 & 리플레이** — 바이너리 로그 파일로 저장하고, 비동기 리플레이 엔진으로
  속도 조절하며 재생
- 설정(config.json) 관리, SSH 터널을 통한 MongoDB 연동
- 모의 패킷 송신 시뮬레이터를 함께 두어 장비 없이 개발·검증

## 스택

WPF · C# · .NET 8 · UDP · GMap.NET · MongoDB
