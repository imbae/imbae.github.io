**UAV 지상시험장비(AVTE, Air Vehicle Test Equipment)** 는 항공기에 탑재되는 여러 계통 장비를
지상에서 자동/수동으로 점검하고 **BIT(Built-In Test, 자체진단)** 결과를 판정하는 WPF 애플리케이션입니다.
방산 프로젝트라 네트워크 구성·규격 수치·기관·기종 정보는 공개하지 않고, 소프트웨어 설계·구현 역량만 적습니다.

## K4586

**K4586**은 NATO의 드론 통신 표준 **STANAG 4586**을 국내 실정에 맞게 **국산화한 프로토콜**입니다.
이 프로젝트에서 **K4586 통신 라이브러리(K4586Link)를 설계·구현**하고, 그 위에서 동작하는 AVTE 클라이언트의
아키텍처를 설계·개발했습니다. 통신 라이브러리는 독립 모듈(Git 서브모듈)로 분리해 다른 GCS에서도 재사용할 수 있습니다.

```
AVTE 클라이언트 (WPF, MVVM)  ── 자동 점검 · 수동 점검 · BIT
        │  Adapter 계층 (메시지 → UI 모델)
        ▼
K4586Link (독립 라이브러리) ── 직렬화/역직렬화 · 체크섬 · UDP 송수신
        │  UDP (멀티캐스트)
   비행체 측  /  지상통제 측
```

## 무엇을 만들었나

### 규격(ICD)에서 코드를 자동 생성하는 제너레이터
수백 개의 메시지·필드를 사람이 C# 클래스로 옮기면 오탈자와 필드 순서 오류로 이어집니다. 규격 문서(ICD)를
읽어 **C# 클래스·enum을 자동 생성**하고, 필드별 메타데이터(단위·최솟값/최댓값·분해능)를 속성(Attribute)으로
붙이는 코드 제너레이터를 만들었습니다. 규격이 바뀌면 재생성만 하면 됩니다.

### K4586 통신 계층
- 바이너리 직렬화/역직렬화, **엔디안 처리**, 체크섬 검증
- UDP 멀티캐스트 송수신, **Producer-Consumer 비동기 큐** 파이프라인 — 패킷 유실·순서 뒤바뀜 없이 동작

### 어댑터 패턴 기반 UI 매핑
통신 원시 데이터를 화면용 정보로 바꾸는 **Adapter 계층**을 제네릭과 속성 기반 자동 매핑으로 설계했습니다.
필드에 "이건 전압이고 정상 범위는 얼마"라고 태그를 달면 판정 로직이 이를 읽어 정상/주의/경고를 결정합니다.
11개 이상 서브시스템을, 규칙만 지키면 등록 코드 없이 UI에 반영되는 구조로 확장했습니다.

### 자동 점검 · BIT
- **CBIT/PBIT/IBIT** 세 유형 지원, Min/Max·주의/경고 구간 **판정 엔진**
- `async/await` + `CancellationToken`으로 여러 점검을 동시에 돌리면서 "중단"에 즉시 반응
- **Handlebars.Net** 템플릿으로 점검 결과를 HTML 보고서로 자동 산출

### 동시성 결함 진단·수정
영상 장비 제어에서 하트비트·사용자 명령·백그라운드 모니터링이 동시에 실행되며 생기던 레지스터 값 오염,
타임아웃 오차, 리소스 누수 등 **8건의 잠재 결함**을 근본 원인 분석 후 수정했습니다
(`SemaphoreSlim`, `volatile`/`Interlocked`, `TaskCompletionSource`).

### ICD Diff Viewer
규격 개정 시 이전/현재 버전의 변경 항목을 한눈에 비교하는 WPF 도구를 만들어, 수작업 대조와 누락을 줄였습니다.
