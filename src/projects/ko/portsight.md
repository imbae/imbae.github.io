모의투자가 아니라 **실투자자가 지금 바로 쓰는 도구**를 목표로 한 Flutter 앱입니다.
보유 종목을 입력하면 지표 분석부터 계좌 유형별 전략, 세금·배당 계산, 리밸런싱까지
한 흐름으로 이어집니다. 로그인 없이 로컬(Drift/SQLite)에 저장합니다.

## 주요 기능

### 포트폴리오 관리
- 보유 종목 CRUD (종목·수량·매수가·매수일), 추가매수 시 평균가 재계산, 부분 매도
- 계좌 유형 분리: 일반국내 / 일반해외 / ISA / 연금저축 / IRP / 금현물
- 계좌별 한도 트래커 (ISA 2,000만원, IRP 연 900만원 등)

### 포트폴리오 분석
- 보유 종목 기술적 지표 일괄 분석 (RSI · MACD · 볼린저 · ATR · OBV)
- 섹터 / 자산군 배분 시각화, 벤치마크(코스피 · S&P 500) 대비 수익률
- 해외 계좌 환율 손익 분리, 자산 추이 그래프
- 건강 점수 (분산 · 절세 · 리스크, S~D 등급)

### 전략 추천
- 계좌 유형별 전략 (ISA → 배당/성장 ETF, IRP → 채권 배분 등)
- 종목별 액션 제안 (추가매수 / 보유 / 분할매도 / 손절 검토)
- 포트폴리오 탭에 [보유 | 분석 | 전략] 통합, AI 총평 + 상세 신호 바텀시트

### 세금
- 해외주식 양도세 계산 (연 250만원 공제 트래킹), 손익통산 시뮬레이터
- ISA / IRP 절세 혜택 계산, 연간 세금 리포트

### 배당
- 종목별 배당 이력 + 연간 예상 배당금, 내 보유 종목 기준 배당락일 캘린더
- 배당 재투자 복리 시뮬레이션, ISA 배당 비과세 표시

### 리밸런싱
- 목표 자산배분 설정 → 현재 vs 목표 차이 시각화 → 액션 플랜 생성

## 구조

- Flutter 3.41 / Dart 3.11, Riverpod 2.x, Clean Architecture (Domain/Data/Presentation)
- 로컬 DB Drift, 라우팅 go_router
- 백엔드는 Python FastAPI (yfinance · FinanceDataReader) — 시세·배당·뉴스·실적·경제지표 제공
- 금융 계산은 부동소수점 오차 방지 패턴(`(x*100).round()/100`) 사용
- AI 분석·세금·배당 수치에는 "참고용, 투자 판단은 본인 책임" 면책 문구 필수

> 시세는 무료 API 기준 15분 이상 지연될 수 있고, 세금·배당 계산은 참고용입니다.
