## 한 장 요약

- 이 사이트는 **미리 만들어 둔 HTML 파일들의 모음**입니다. 방문자가 봤을 때
  서버에서 계산하는 게 없습니다(그래서 "정적" 사이트).
- 내가 고치는 건 `src/` 폴더 안의 파일이고, **Eleventy**라는 도구가 그걸
  실제 HTML(`_site/` 폴더)로 바꿔 줍니다. 이 과정을 "빌드"라고 부릅니다.
- 대부분의 내용 수정은 **딱 세 군데**만 건드리면 됩니다:
  - `src/_data/books.js` — 독서 기록
  - `src/_data/projects.js` + `src/projects/` — 프로젝트
  - `src/notes/` — 글
- 고친 뒤 `git push` 하면 GitHub가 알아서 빌드해서 배포합니다. 1~2분 뒤
  `https://imbae.github.io` 에 반영됩니다.
